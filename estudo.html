Favoritos + localStorage

Guia de estudo — Elder • Projeto CineBusca (Web 1)

As 3 histórias que abrem todas as portas

HISTÓRIA 1

Como eu SALVO?

localStorage.setItem(
  CHAVE_FAVORITOS,
  JSON.stringify(favoritos)
);
"Converto o array em string com JSON.stringify e gravo no localStorage."
HISTÓRIA 2

Como eu LEIO?

var dados = localStorage.getItem(CHAVE_FAVORITOS);
if (dados === null) return [];
return JSON.parse(dados);
"getItem retorna null se nunca gravei nada, então devolvo array vazio. Senão, JSON.parse converte a string de volta em array."
HISTÓRIA 3

Como eu VERIFICO se já está favoritado?

for (var i = 0; i < favoritos.length; i++) {
  if (favoritos[i].imdbID === imdbID) return true;
}
return false;
"Percorro o array procurando o ID. Se acho, retorno true. Se termino o loop sem achar, retorno false."

O resto são combinações das 3

  • alternarFavorito — Verifica (h3) → remove ou adiciona → salva (h1)
  • renderizarFavoritos — Lê (h2) → percorre e cria os cards
  • sincronizarBotoesFavorito — Verifica (h3) → atualiza estrelas na tela
  • criarBotaoFavorito — Verifica (h3) pra desenhar ★ ou ☆
  • Botão "Limpar todos" — localStorage.removeItem (variação da h1)

🎤 Perguntas que o professor vai fazer

❓ "Por que JSON?"
Porque localStorage só aceita string. JSON converte array/objeto ↔ string.
❓ "E se o usuário abrir o site pela primeira vez?"
getItem retorna null. Meu código verifica e devolve array vazio pra não quebrar.
❓ "Se eu fechar o navegador os favoritos somem?"
Não. localStorage persiste até limpar o cache. Diferente do sessionStorage.
❓ "E em outro navegador?"
Não aparecem. localStorage é isolado por navegador/perfil. Pra sincronizar precisaria de banco de dados no servidor.
❓ "Por que confirmação no 'Limpar todos'?"
Ação destrutiva sem desfazer. Uso confirm() do navegador — se cancelar, a função sai.
❓ "Onde vejo o localStorage funcionando?"
F12 → Application → Local Storage → chave cinebusca_favoritos.
❓ "Por que 'criarBotaoFavorito' é função separada?"
Se criasse o listener dentro do for, todos os botões clicariam no mesmo filme por causa de closure. Função separada garante escopo próprio pra cada botão.
❓ "O que é dataset.imdbid?"
Forma JS de acessar atributo data-imdbid do HTML. Serve pra achar todos os botões do mesmo filme com querySelectorAll.
❓ "Tem limite de tamanho no localStorage?"
Cerca de 5MB por origem. Mais que suficiente pra centenas de filmes.
❓ "É a mesma coisa que cookie?"
Não. Cookie vai pro servidor em cada requisição. localStorage fica só no navegador, não trafega na rede.
